# 使い方

これは **一回渡すための道具**です。同期ソフトではありません。差分の追跡も、
削除の伝播も、競合の解決もしません。指定したものを、その一回だけ運びます。

---

## 2 つの流れ

### 流れ A — 内側から外側へ

内側の PC / VPS にあるものを、Tailscale の外にある PC へ渡す。

1. **内側の PC で**送るものを用意する
   `npm run relay -- outbox add "経費精算 8月" "C:\work\経費精算"`
2. **スマホで**「母艦から受け取って、向かいの画面へ流す」を選び、それを選ぶ
3. スマホがコードを表示する
4. **外側の PC で** `pub-transfer.bat` →「受け取る」→「カメラで読み取る」
5. 外側の PC に「保存しました」が出たら終わり

### 流れ B — 外側から内側へ

外側の PC にあるものを、内側の PC / VPS へ渡す。

1. **外側の PC で** `pub-transfer.bat` →「送る」→ ファイル／フォルダーを選ぶ →「送信をはじめる」
2. **スマホで**「向かいの画面を読み取って、母艦へ渡す」
3. 読み取れたら、渡す先（母艦の受け取り先）を選ぶ
4. 「渡しました」が出たら終わり

---

## 画面の読み方

### いま、どちらへ向かっているか

画面の上に必ず出ています。

```
送る    ● 事務所デスクトップ（ここ）  →  ○ 向かいのカメラ
受け取る ○ 向かいの画面  →  ● 事務所デスクトップ（ここ）
```

スマホでは 3 段になり、`内 → 外` / `外 → 内` の 2 文字が先頭に付きます。
`●` が今いる場所、`✓` は済んだ場所です。

### 送っている側は「完了」と言いません

画面からカメラへは一方通行で、**相手が受け取れたかどうかを知る方法がありません。**
だから送信側は「表示を終わりました」としか言いません。
**受け取り側の画面に「保存しました」が出たことを確かめてください。**

### 保存されるまで

受け取ったものは、

1. 全体のハッシュが一致すること
2. 中の 1 ファイルずつのハッシュが一致すること

の両方を通ってから、はじめてディスクに書かれます。**一致しなければ 1 件も
保存しません。**「何件かは無事でした」とは言いません — その判断は、
全体が見えている人がするものです。

保存は保存先の中に新しいフォルダーを作って行います。同じ名前があれば
`名前 (2)` になります。既定では**黙って上書きしません**（設定で変えられます）。

受け取ったファイルをこのアプリが開くことはありません。フォルダーを開くだけです。

---

## 受け取り方は 2 つある

### カメラで読み取る

相手の画面に映る連続コードを、動画のまま読み続けます。**速いのはこちらです。**

途中でやめると、それまでに読めた分は残りません。もう一度、最初から読みます。

### 読み取り機で 1 枚ずつ読む

二次元コードのリーダー（QR 対応の機種）で、表示されたコードを 1 枚ずつ読みます。
**少量向けです**（およそ 48 KB まで）。

- 画面には 40 個などのマス目が出ます。読めた番号は塗られます
- 足りない番号は下に **数字で名指し**されます（例: `あと 2 枚 ── 3, 6`）
- 途中でやめても、**読めた枚数はそのまま残ります**。続きから読めます
- 入力欄にフォーカスがある状態で読み取ってください
- **日本語入力（IME）は切ってください。** リーダーはキーボードとして文字を
  打つので、かなに変換されると読み取れません

**一次元のバーコードリーダーでは読めません。** このコードは QR です。

COM ポートに文字を送る設定のリーダーを使う場合は、設定で「COM ポートから
受け取る」に切り替え、ポートを選んでください。

---

## 送るものの大きさ

一度に送れるのは既定で **16 MB** までです。形式としてはもっと運べますが、

- 光の経路は速くありません（16 MB でも数分かかります）
- 中継するのはスマホで、大きすぎるとタブごと落ちます
- **途中から再開する方法はありません**

選んだ時点で「かかる目安」が出ます。長すぎるようなら分けて送ってください。

---

## 送るときの調整

うまく読み取れないときは、送る側の「送り方」を変えます。

| 設定 | 読めないとき | 速くしたいとき |
|---|---|---|
| 1 秒あたりの枚数 | 減らす（10 枚） | 増やす（30 枚） |
| 1 枚あたりの量 | 減らす（少なめ） | 増やす（最大） |

そのほか、画面の明るさを上げる、カメラを近づける、画面全体が映るところまで
下がる、が効きます。

---

## 運べないもの・落ちるもの

送る側で自動的に外れます（外した数は画面に出ます）。

- リンク（シンボリックリンク、ジャンクション）
- 通常ファイル以外（デバイス、パイプなど）
- 名前が長すぎるもの（1 つ 180 文字、全体 200 文字まで）
- 階層が深すぎるもの（32 段まで）
- Windows で作れない名前（`CON` `PRN` `COM1` など、末尾がドットや空白のもの）

**空のフォルダーは運びません。** ファイルの一覧として運ぶので、中身の無い
フォルダーは向こう側に現れません。更新日時と権限も運びません。

---

## 見えている情報について

**光の経路は暗号化されていません。** 画面に出ているものは、その場のどのカメラ
からも読めます。この道具が与える性質は「間に network が無いこと」であって、
**秘匿ではありません**。覗かれて困るものを、覗ける場所で表示しないでください。

Tailscale 側は別で、登録した端末だけが受信先に触れられます。端末を失ったときは
`npm run relay -- device revoke <id>` で登録を取り消してください。
